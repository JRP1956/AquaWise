Steps, in order

  1. 1Move everyone away from the water.
  2. 2Switch off the flat’s main breaker only if you can reach it without standing in water.
  3. 3Close the main inlet valve. If it is a common line, ask security to close the building valve.
  4. 4Call your society admin. Call 112 for an electrical hazard or injury.
  5. 5If the burst is on the road main, report it to the municipal helpline.
  6. 6File a complaint so your society can track the repair.
